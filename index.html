Checkpoint 02 – Sistema de Avaliação de Estoque e Tendência de Vinhos

Sobre o projeto

Este sistema cadastra vários vinhos em sequência usando prompt() e alert(). Para cada vinho ele valida os dados, classifica a safra (jovem, amadurecido ou antigo) e avisa quando o estoque está baixo.

No final, exibe um resumo com o total de cadastros, os vinhos com estoque baixo e o vinho mais antigo.

Abra o console (F12) para ver os detalhes. Recarregue a página para cadastrar novamente.
